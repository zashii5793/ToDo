# タスク管理 — 理論と実践

「当日」と「翌日」の2枚だけで回す、繰り越し式のToDoツールです。**理論（考え方）** と **タスク管理（実践）** の2タブ構成。インストール不要・ブラウザだけで動き、入力は自動保存されます。共有用の書き出しは、**メモ帳にそのまま貼れるプレーンテキスト**に対応しました。

👉 **公開URL（GitHub Pages）:** `https://zashii5793.github.io/ToDo/`
（初回のみ Settings › Pages で公開設定が必要です。手順は後述。）

---

## ✨ オススメポイント

- **2枚だけで回すシンプル運用** — 「当日ToDo」と「翌日ToDo」の2列。夜に書き出し、朝に繰り上げるだけ。
- **メモ帳用にコピー** — 各列の「📋 メモ帳用にコピー」で、メモ帳・日報にそのまま貼れるプレーンテキストをクリップボードへ。（従来のChatWork向け整形から変更）
- **HTMLで書き出す** — 日付入りのToDo一覧を `todo_YYYYMMDD.html` として保存・添付できます。
- **翌日へ繰り上げ** — 翌日ToDoをワンクリックで当日へ。翌朝の切り替えがすぐ終わります。
- **ドラッグで並べ替え** — 行頭の `≡` をつかんで優先順位を入れ替え。
- **→翌日 で送る** — 当日の残りを翌日ToDoへコピー。
- **完了を数える** — 「記入◯件／完了◯件」を自動集計。毎日の消化数がそのまま成長の指標に。
- **理論タブ内蔵** — タスク管理を「成長のトレーニング」として続けるための5原則・優先順位マトリクス・1日の回し方を収録。編集モードで自分用に書き換え＆PDF出力も可能。
- **自動保存・完全ローカル** — 入力はブラウザ内（localStorage）に保存。サーバーには何も送信しません。

## 📝 使い方

### タスク管理タブ

1. **書き出す** — 「＋ 行を追加」または各行で Enter を押して、やることを入力。
2. **消し込む** — 済んだら丸チェックをオン（取り消し線で消込表示）。
3. **翌日へ送る** — 残ったものは当日側の「→翌日」で翌日ToDoへコピー。
4. **並べ替える** — 行頭の `≡` をドラッグして優先順位を調整。
5. **翌朝** — ツールバーの「▶ 翌日へ繰り上げ」で翌日ToDoを当日へ移動。
6. **共有** — 「📋 メモ帳用にコピー」でテキストをコピー、または「⬇ HTMLで書き出す」でファイル保存。

| ツールバー | 内容 |
| --- | --- |
| ▶ 翌日へ繰り上げ | 翌日ToDoをまとめて当日ToDoへ移動 |
| ⬇ HTMLで書き出す | 現在のToDoを日付入りHTMLファイルで保存 |
| 当日をクリア | 当日ToDoを全消去 |
| ✎ 文言を編集 | 見出し・説明文を自分用に書き換え（自動保存） |

### 理論タブ

- タスク管理を「毎日速くなるトレーニング」として続けるための考え方（5原則・優先順位マトリクス・1日の回し方）。
- **✎ 編集モード** … 本文を直接書き換え（自動保存）
- **⬇ PDF出力** … 印刷画面から「PDFで保存」を選択
- **元に戻す** … 本文を初期状態に戻す

## 📋 コピー／書き出しの形式

**メモ帳用にコピー（プレーンテキスト）**

```
■ 当日のToDo（2026/7/12）
1. ☐ 永海様クルマ引取
2. ☑ 松本様、リース再計算（タント）
```

**HTMLで書き出す** … 従来と同じ、日付入りの `todo_YYYYMMDD.html`（当日／翌日の2セクション）。

## 🌐 公開（GitHub Pages）の設定

1. リポジトリの **Settings › Pages**
2. **Source** を **Deploy from a branch**
3. Branch を対象ブランチ／フォルダ `/(root)` にして **Save**
4. 数分後 `https://zashii5793.github.io/ToDo/` で公開されます

> 反映直後はCDN・ブラウザのキャッシュで旧版が見えることがあります。`⌘/Ctrl + Shift + R`（スーパーリロード）か、URL末尾に `?v=2` を付けて開いてください。

## ❓ FAQ

**Q. データはどこに保存されますか？**
A. お使いのブラウザ内（localStorage）だけです。外部送信はありません。端末やブラウザをまたぐと共有されません。

**Q. 他の人に渡したい。**
A. 「メモ帳用にコピー」でテキストを貼るか、「HTMLで書き出す」のファイルを共有してください。
