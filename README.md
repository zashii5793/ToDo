# ToDoリスト

当日と翌日の「やること」をサッと整理して、**メモ帳（Windowsのメモ帳）にそのまま貼れるテキスト（.txt）** で書き出せる、シンプルなToDoツールです。インストール不要・ブラウザだけで動きます。

👉 **公開URL（GitHub Pages）:** `https://zashii5793.github.io/ToDo/`
（初回のみ、リポジトリの Settings › Pages で公開設定が必要です。設定方法は後述します。）

---

## ✨ オススメポイント

- **インストール不要** — ブラウザでページを開くだけ。スマホでもPCでも使えます。
- **自動保存** — 入力内容はブラウザ内（localStorage）に自動保存。次に開いたときも続きから使えます。
- **メモ帳にそのまま貼れる** — ボタン1つで、Windowsのメモ帳で文字化けせず開ける `.txt` を書き出せます（UTF-8 BOM付き）。
- **当日／翌日の2枠で管理** — 「今日やること」と「明日やること」を分けて整理できます。
- **ワンクリックで繰り越し** — 終わらなかった翌日ぶんを、翌朝そのまま当日へ移動できます。
- **完了はチェックで見える化** — チェックを入れると取り消し線が付き、済んだものが一目で分かります。
- **安心設計** — すべてブラウザ内で完結。サーバーには何も送信されません。

---

## 📝 使い方

1. **ページを開く** — 公開URL、または `index.html` をブラウザで開きます。
2. **やることを追加** — 入力欄に文字を入れて `Enter` キー、または「追加」ボタンを押します。
   - 「当日のToDo」＝今日やること／「翌日のToDo」＝明日やること
3. **完了したらチェック** — 左のチェックボックスをオンにすると取り消し線が付きます。
4. **編集・削除** — 文字はそのままクリックして書き換え可能。右の「×」で削除します。
5. **メモ帳用に書き出す** — 「メモ帳用に書き出す（.txt）」ボタンを押すと、テキストファイルがダウンロードされます。
   - ダウンロードした `todo_YYYYMMDD.txt` を **メモ帳で開く／添付** してご利用ください。

### 便利ボタン

| ボタン | 内容 |
| --- | --- |
| メモ帳用に書き出す（.txt） | 現在のToDoを、メモ帳で開けるテキストファイルとして保存します。 |
| 翌日のToDoを当日へ繰り越す | 翌日ぶんをまとめて当日へ移動します（翌朝の切り替えに便利）。 |
| 完了済みを削除 | チェック済みの項目だけをまとめて消します。 |
| すべて消去 | 当日・翌日の全項目を消去します。 |

## 📄 書き出されるテキストの例

```
■ ToDoリスト
書き出し日時：2026/7/12 11:19:26

【当日のToDo】
1. [ ] 資料をまとめる
2. [x] メール返信

【翌日のToDo】
1. [ ] 打ち合わせの準備
```

- 完了した項目は `[x]`、未完了は `[ ]` で表示されます。
- Windowsのメモ帳で開いても日本語が文字化けしないよう、UTF-8 BOM付きで保存されます。

## 🌐 公開（GitHub Pages）の設定方法

一般の人が使えるように公開するには、GitHub Pages を有効にします。

1. GitHubで本リポジトリを開く
2. **Settings › Pages** を開く
3. **Build and deployment › Source** を **Deploy from a branch** にする
4. Branch を `main`（またはデフォルトブランチ）／フォルダを `/ (root)` にして **Save**
5. 数十秒〜数分後、`https://zashii5793.github.io/ToDo/` で公開されます

公開後は、このURLを共有するだけで誰でもブラウザから利用できます。

## ❓ よくある質問

**Q. 入力したデータはどこに保存されますか？**
A. お使いのブラウザ内（localStorage）だけに保存されます。外部には送信されません。別の端末やブラウザとは共有されない点にご注意ください。

**Q. データを他の人と共有したいです。**
A. 「メモ帳用に書き出す」で `.txt` を保存し、そのファイルを共有してください。

**Q. 履歴を残したい／別のPCでも見たい。**
A. 書き出した `.txt` をメモ帳やクラウド（ドライブ等）に保存しておくと、いつでも見返せます。
